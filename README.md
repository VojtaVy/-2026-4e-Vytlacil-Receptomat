# -2026-4e-Vytlacil-Receptomat
Cílem projektu je vytvořit responzivní webovou aplikaci pro inteligentní vyhledávání a plánování receptů na základě surovin, které má uživatel aktuálně doma. Uživatel v přehledném rozhraní zaškrtne dostupné ingredience a aplikace mu okamžitě vyfiltruje vhodné recepty včetně postupu přípravy, doby vaření a seznamu případně chybějících surovin.
